Architecture & Conversational Guardrails

Strict Server-Side Validation

Every field submitted by the voice agent or REST API is validated independently. Client and LLM inputs are never trusted implicitly. If invalid input is received, granular error details are returned for targeted conversational re-prompting.

Zero-Loss SQLite Persistence

Built with better-sqlite3 configured in WAL mode (Write-Ahead Logging). Transactions are immediately flushed to disk. Records survive restarts and crash recoveries.

Edge Case Safeguards

  • Connection Drop Mid-Call: No patient row is inserted until explicit verbal confirmation is given at the read-back stage. Prevents orphaned dirty records.
  • Duplicate Detection: Incoming phone numbers are matched against active records. If found, the agent offers an update path instead of creating duplicate records.
  • DB Write Failure: If writing to disk fails after confirmation, the agent speaks an empathetic retry message rather than silence.
  • Mid-Flow Corrections: Callers can spell or correct fields at any point without restarting the entire questionnaire.
